# repetition_penalty 通俗讲解
## 一、基本定义
`repetition_penalty` = **重复惩罚系数**，作用是**抑制模型重复话术、重复句子、循环复读**。
取值范围：**> 1.0**，RAG/问答场景常用 `1.05 ~ 1.2`。

---

## 二、取值含义（直白版）
- **= 1.0**：不做任何重复惩罚，模型容易原地复读、来回说一样的话
- **1.01 ~ 1.05**：轻微惩罚（推荐日常/RAG使用），小幅抑制重复，不影响正常表达
- **1.05 ~ 1.1**：中等惩罚，明显减少短句、关键词重复
- **1.1 ~ 1.2**：较强惩罚，适合长文本、文案、总结；**不建议医疗/严谨问答拉太高**
- **> 1.2**：惩罚过重，容易出现**语句断裂、语义生硬、用词怪异**

---

## 三、结合你当前场景（Qwen3.5-4B-Medical + 医疗RAG）
### 推荐配置
```
repetition_penalty: 1.05
```
理由：
1. 医疗问答要求语句严谨、术语准确，**惩罚不能太高**，否则专业表述变形；
2. 1.05 刚好克制简单重复，又不破坏原文语义和医学术语。

### 不同现象对应调参
1. **回答来回重复同一句话/关键词**
   → 调高到 `1.08 ~ 1.1`
2. **回答断断续续、用词别扭、逻辑断裂**
   → 调低回 `1.03 ~ 1.05`
3. **完全不重复、输出正常**
   → 保持 `1.05` 即可

---

## 四、和其他参数简单区分（避免混淆）
- `temperature`：控制**随机性、创造力**（越低越严谨）
- `max_tokens`：控制**回答最大长度**
- `repetition_penalty`：只负责**防复读、防重复**
---


**频率惩罚（frequency_penalty）**：按词出现次数“累进扣分”，**出现越多次，罚得越重**，用来抑制同一个词反复刷屏。

### 一、一句话原理
公式（简化）：
```
新概率 = 原概率 −（已出现次数 × frequency_penalty）
```
- 出现1次：扣一点
- 出现3次：扣三倍
- 出现10次：扣十倍

### 二、取值范围与效果（-2.0 ~ 2.0）
- **0.0（默认）**：不惩罚，爱用啥用啥
- **0.1 ~ 0.3**：轻度抑制，日常/RAG常用
- **0.3 ~ 0.6**：明显减少高频词，用词更多样
- **0.6 ~ 1.0**：强抑制，适合长文/总结
- **>1.0**：容易用词怪异、句子生硬，慎用
- **负数**：鼓励重复（几乎不用）

### 三、和你之前问的 repetition_penalty 区别
很多人搞混，这里直白对比：

- **frequency_penalty（频率惩罚）**
   - 规则：**次数越多，罚越重**
   - 类比：**累进税**（赚越多税越高）
   - 解决：同一个词反复用（如“非常非常非常”）

- **repetition_penalty（重复惩罚）**
   - 规则：**只要出现过，就统一罚**（1次和10次一样）
   - 类比：**闯红灯一律扣6分**
   - 解决：整句/短语复读、循环

### 四、医疗RAG（Qwen3.5-4B-Medical）推荐
- **frequency_penalty：0.2 ~ 0.4**
- **repetition_penalty：1.05**
  理由：
- 医疗术语要稳定，不能太“花样”
- 既要防“患者患者患者”，又不能把医学词罚没

### 五、快速记忆
- **frequency_penalty = 按次数累进 → 防单词刷屏**
- **repetition_penalty = 出现就罚 → 防整句复读**

# presence_penalty 存在惩罚
## 一、核心定义
**存在惩罚**，作用：只要词汇/短语**在当前上下文里出现过**，就统一降低再次选用的概率，**和出现次数无关**。
取值范围：`-2.0 ~ 2.0`，默认 `0`。

## 二、取值效果
- `0`：不生效，无任何限制
- `0.1 ~ 0.3`：轻度惩罚，常规场景首选
- `0.3 ~ 0.6`：中度惩罚，主动引导模型使用新词汇、新表述
- `0.6 ~ 1.0`：强惩罚，容易偏离原文、改写过度，严谨场景慎用
- 负数：鼓励重复，几乎不用于 RAG/问答

## 三、三大惩罚横向对比（重点区分）
结合你医疗 RAG 场景，一次性讲清三者差异、适用问题、推荐值：

| 参数 | 中文名 | 核心规则 | 解决问题 | 医疗RAG推荐值 |
| ---- | ---- | ---- | ---- | ---- |
| repetition_penalty | 重复惩罚 | 只要出现过，固定扣分（次数不影响） | 整句、短语循环复读 | 1.05 |
| frequency_penalty | 频率惩罚 | 出现次数越多，扣分越多（累进） | 单个词语反复堆砌 | 0.2~0.3 |
| presence_penalty | 存在惩罚 | 只要在上文出现过，就抑制复用（不计次数） | 反复沿用旧句式、旧词汇，表达单一 | 0.1~0.2 |

### 通俗举例
上下文多次出现「腹膜透析」：
1. `repetition_penalty`：防止整句 **“腹膜透析注意事项……腹膜透析注意事项”** 重复
2. `frequency_penalty`：防止 **“腹膜透析、腹膜透析、腹膜透析”** 词语堆砌
3. `presence_penalty`：引导模型换表述，比如改用「腹透治疗」「透析方案」，避免全程只使用同一个词

## 四、场景搭配 & 避坑
### 1. 你的环境最终组合（Qwen3.5-4B-Medical + RAGFlow）
```json
"repetition_penalty": 1.05,
"frequency_penalty": 0.2,
"presence_penalty": 0.1
```
- 兼顾防复读、防词语堆砌，同时轻微丰富表达；
- 医疗术语优先保留原意，不会过度改写。

### 2. 调参指引
1. 回答句式单调、用词单一 → 小幅提高 `presence_penalty`（最高不超 0.3）
2. 专业医学词汇被替换、语义跑偏 → 调低至 `0` 或 `0.05`
3. 三者不要同时拉到高值（＞0.5），极易出现语句断裂、术语错误。

## 五、补充说明
1. Ollama / OpenAI 接口均原生支持这三个参数，RAGFlow 可直接在 `llm_config` 中配置；
2. 纯严谨医疗问诊/条文解读：建议 `presence_penalty=0`，优先保证原文术语不变；
3. 科普、总结类场景：开启 `0.1~0.2`，让表述更自然多样。

# 相似度阈值、向量相似度权重、TOP-N（Top-K）
> 结合你用的 **RAGFlow + Qwen3.5-4B-Medical（医疗RAG） 给出推荐值和调参逻辑。

---

## 一、相似度阈值（Similarity Threshold）
### 作用
过滤掉**相关性太低**的文本块，只有**混合相似度 ≥ 阈值**的片段才会进入下一步，避免垃圾信息进 LLM。

### 计算（RAGFlow）
```
混合相似度 = 关键词相似度 × 关键词权重 + 向量相似度 × 向量权重
```
阈值就是这个**混合分**的门槛。

### 取值范围与效果
- **0.0～0.4**：宽松，召回多、噪音多（易答偏）
- **0.4～0.6**：中等，通用场景常用
- **0.6～0.8**：严格，**医疗/权威问答首选**
- **>0.8**：极严，容易漏关键信息、召回太少

### ✅ 医疗RAG推荐
**0.65 ～ 0.75**
- 腹膜透析/医疗问答：**0.7**
- 理由：既要准、又不能把正确答案滤掉

---

## 二、向量相似度权重（Vector Weight）
### 作用
控制**语义（向量）**和**关键词**哪个更重要：
- 权重越高 → 越看重**语义相似**（哪怕用词不一样）
- 权重越低 → 越看重**字面关键词匹配**

### 关系（RAGFlow）
```
关键词权重 + 向量权重 = 1.0
```
例如：向量权重=0.7 → 关键词权重=0.3。

### 取值含义
- **0.0～0.3**：几乎只认关键词（适合标准术语查询）
- **0.4～0.6**：关键词+语义均衡（通用）
- **0.7～0.9**：优先语义（适合口语化、医学同义改写）
- **1.0**：纯向量，完全不管关键词

### ✅ 医疗RAG推荐
**0.7 ～ 0.8**
- 腹膜透析场景：**0.75**
- 理由：
    - 患者提问口语多（“肚子胀”→“腹透相关腹胀”）
    - 医学术语同义多（腹膜透析/腹透）
    - 向量权重高，能抓**真实语义**

---

## 三、TOP-N（Top-K）
### 作用
在**超过阈值的片段里**，只取**最相关的前 N 条**送给 LLM：
- N 越大 → 信息越多、上下文越长、越容易混
- N 越小 → 信息精炼、但容易缺关键细节

### 取值范围与效果
- **1～3**：短答案、精准、易断章
- **3～5**：平衡（**RAG默认常见值**）
- **5～8**：长答案、全面、可能冗余
- **>8**：上下文拥挤，LLM容易乱、丢重点

### ✅ 医疗RAG推荐
**3 ～ 5**
- 腹膜透析问答：**4**
- 理由：
    - 医疗答案需要**依据充分**
    - 4 条刚好够 LLM 组织完整回答，又不超限

---

## 四、三者关系（一句话串起来）
1. **相似度阈值=筛子**：先把“不相关”的全扔掉；
2. **向量权重=天平**：决定按“语义”还是“关键词”筛；
3. **TOP-N=数量**：筛完后，最多留几条给大模型。

---

## 五、直接可用的医疗RAG配置（RAGFlow）
```
相似度阈值：0.7
向量相似度权重：0.75
TOP-N：4
```

### 调参速查（出现问题怎么改）
- 回答不准、像幻觉 → **提高阈值到 0.75**
- 漏关键知识点 → **降低阈值到 0.65 或 TOP-N=5**
- 口语化问题答不好 → **提高向量权重到 0.85**
- 术语识别差 → **降低向量权重到 0.6**
- 回答太长、啰嗦 → **TOP-N=3**
