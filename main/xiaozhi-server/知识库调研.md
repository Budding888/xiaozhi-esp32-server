## 一、安装 RAGFlow（Windows 最简单方式：Docker Desktop）
### 1. 安装 Docker Desktop
直接下载安装：
https://www.docker.com/products/docker-desktop/

安装完 **重启电脑**。

### 2. 下载 RAGFlow
新建一个文件夹，例如：
`D:\ragflow`

在文件夹里 **新建文件 `docker-compose.yml`**，内容复制下面全部：
```yaml
version: '3'

services:
  elasticsearch:
    image: elasticsearch:8.11.0
    container_name: es
    environment:
      - discovery.type=single-node
      - xpack.security.enabled=false
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
    ports:
      - "9200:9200"
    networks:
      - ragflow

  mysql:
    image: mysql:8.0
    container_name: mysql
    environment:
      - MYSQL_ROOT_PASSWORD=root
      - MYSQL_DATABASE=ragflow
    ports:
      - "3306:3306"
    networks:
      - ragflow

  redis:
    image: redis:7-alpine
    container_name: redis
    ports:
      - "6379:6379"
    networks:
      - ragflow

  ragflow:
    image: infiniflow/ragflow:latest
    container_name: ragflow
    depends_on:
      - elasticsearch
      - mysql
      - redis
    environment:
      - SPRING_DATASOURCE_USERNAME=root
      - SPRING_DATASOURCE_PASSWORD=root
      - SPRING_DATASOURCE_URL=jdbc:mysql://mysql:3306/ragflow
      - SPRING_REDIS_HOST=redis
      - ELASTICSEARCH_HOST=es
    ports:
      - "8008:8008"
    networks:
      - ragflow

networks:
  ragflow:
```

### 3. 启动 RAGFlow
在 `D:\ragflow` 文件夹里 **打开 CMD**，运行：
```bash
docker-compose up -d
```

等待 1~2 分钟，启动完成。

# nomic-embed-text 与 bge-m3的区别
先给结论：  
** 二者都属于 文本嵌入（Embedding） 类型的模型
**nomic-embed-text = 轻量、英文强、速度快、省资源**  
**bge-m3 = 全能、多语言、精度高、支持混合检索**

下面从核心参数、能力、适用场景三方面对比。

---

## 一、基础参数对比

| 项目 | nomic-embed-text (v1.5) | bge-m3 |
|---|---|---|
| 开发机构 | Nomic AI | 北京智源研究院 BAAI |
| 参数量 | ~137M（很小） | ~569M（中等） |
| 模型大小 | ~274MB（Ollama） | ~2.27GB |
| 向量维度 | 768（支持缩到 512/256…） | 1024 |
| 上下文长度 | 8192 token | 8192 token |
| 语言能力 | 英文为主，中文一般 | **100+ 语言，中文很强** |
| 许可证 | Apache 2.0（完全开源） | 商用友好开源 |

---

## 二、核心能力差异（最关键）

### 1）nomic-embed-text：轻量高效型
- **只有稠密向量（Dense）**：只能做纯语义相似度
- **英文效果好、速度极快**：CPU 也能跑很快
- **使用要加前缀**：  
  - 文档：`search_document: 文本`  
  - 查询：`search_query: 文本`  
  （Ollama/RAGFlow 会自动加）
- **优势**：小、快、省内存，适合 7B/14B 模型一起部署

### 2）bge-m3：全能三合一（M3 的含义）
- **多功能（Multi‑Functionality）**：一个模型同时输出三种向量
  - **Dense 稠密向量**：语义相似度（和 nomic 类似）
  - **Sparse 稀疏向量**：类似 BM25，关键词精确匹配
  - **Multi‑vector 多向量**：细粒度语义对齐（长文档更强）
- **多语言（Multi‑Linguality）**：中英都很强，小语种也支持
- **多粒度（Multi‑Granularity）**：短句到长文档都稳

一句话：**bge-m3 一个顶多个，能做“稠密+稀疏”混合检索，召回率更高**。

---

# 6. bge-reranker-v2-m3 最全极简教程
**原理 + 安装 + RAGFlow配置 + 效果判断**，全部给你讲人话、一步到位。

BGE-Reranker-v2-M3 是北京智源研究院（BAAI）推出的轻量级重排序模型，基于 BGE-M3-0.5B 架构优化，专为多语言检索任务设计，尤其强化了中英文混合场景下的性能。
其核心定位是为RAG流程提供高效的上下文重排序能力，通过过滤无关内容、提升相关段落优先级，显著改善生成式AI的准确性和响应速度。
---

# 一、原理（1分钟看懂）
## 它是什么？
**bge-reranker-v2-m3 = 中文最强、最轻量、本地免费的重排序（Rerank）模型**

## 它做什么？
1. **检索阶段**：Embedding 先粗召回一堆文档（比如 30 条）
2. **重排序阶段**：`bge-reranker-v2-m3` 给这 30 条打分
   → **把最相关的排前面，不相关的丢后面**

## 核心优势
- **体积超小（只有 1.3GB）**
- **CPU 就能跑，速度极快**
- **中文效果吊打绝大多数模型**
- **免费、本地、不上云、隐私安全**

## 一句话总结
