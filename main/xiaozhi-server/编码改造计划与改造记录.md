# 编码改造计划：AgentScope 2.0 多智能体框架整合

> **基于**: 小智项目-医疗大模型+知识库+通用LLM 生产级融合方案2.md  
> **方案**: 方案A (Adapter/Wrapper 整合)  
> **周期**: 4 Phase，约 3-4 天  
> **风险**: 🟢 低 (legacy 模式永久保底)

---

## 一、需求概述

将 **AgentScope 2.0 Python 版** 以 Adapter/Wrapper 模式整合进现有 xiaozhi-esp32-server，解决以下核心痛点：

1. **chat() 臃肿**（350行）：同时管理意图路由、工具调用递归(depth=5)、医疗路由、异常处理
2. **深度递归控制**：`MAX_DEPTH=5` 和 `tool_call_stats` 是硬编码的手动递归控制
3. **非线程安全风险**：V2 并行流中通用LLM的流式状态可能冲突
4. **配置直接读文件**：`_get_medical_config()` 读取 `config.yaml` 而非使用内存中已合并的 `conn.config`

**核心原则**：保留全部现有功能，`AgentMode=legacy/agentscope` 可切换，灰度上线。

##### `core/agentscope/model_wrapper.py`

```python
from agentscope.models import ModelWrapperBase
from agentscope.message import Msg

class XiaozhiLLMWrapper(ModelWrapperBase):
    """
    适配现有 xiaozhi LLM Provider 到 AgentScope 模型接口
    
    AgentScope ReActAgent 通过此包装器调用现有的 LLM Provider，
    无需修改现有 Provider 实现。
    """
    
    def __init__(self, llm_provider, config: dict = None):
        self.llm = llm_provider          # 现有 LLM Provider 实例
        self.model_name = getattr(llm_provider, "model_name", "xiaozhi-llm")
    
    def __call__(self, messages: list[Msg], **kwargs) -> Msg:
        # 转换消息格式: Msg → xiaozhi dialogue
        dialogue = self._convert_messages(messages)
        
        # 调用现有 LLM Provider
        result = ""
        for chunk in self.llm.response(
            session_id=kwargs.get("session_id", ""),
            messages=dialogue,
        ):
            result += chunk
        
        return Msg("assistant", result, "assistant")
    
    def _convert_messages(self, msgs: list[Msg]) -> list[dict]:
        """将 AgentScope Msg 列表转换为 xiaozhi dialogue 格式"""
        dialogue = []
        for msg in msgs:
            role = "user" if msg.role == "user" else "assistant"
            dialogue.append({"role": role, "content": str(msg.content)})
        return dialogue
```

##### `core/agentscope/toolkit_wrapper.py`

```python
from agentscope.tool import Toolkit, FunctionTool
from plugins_func.register import all_function_registry

class XiaozhiToolkitWrapper(Toolkit):
    """
    适配 xiaozhi 现有插件系统到 AgentScope Toolkit
    
    将 @register_function 注册的现有插件包装为 AgentScope FunctionTool，
    使 ReActAgent 可以调用现有的插件系统。
    """
    
    def __init__(self, conn, function_names: list[str] = None):
        self.conn = conn
        tools = []
        
        registry = all_function_registry
        names = function_names or list(registry.keys())
        
        for name in names:
            func_item = registry.get(name)
            if not func_item:
                continue
            
            func_desc = func_item.description.get("function", {})
            tool = FunctionTool(
                name=name,
                description=func_desc.get("description", ""),
                function=self._wrap_func(func_item),
                parameters=func_desc.get("parameters", {}),
            )
            tools.append(tool)
        
        super().__init__(tools)
```

##### `core/connection.py` 集成点

```python
class ConnectionHandler:
    def __init__(self, config, ...):
        # ... 保留现有初始化 ...
        
        # AgentScope 模式标志
        self.agent_mode = config.get("selected_module", {}).get(
            "AgentMode", "legacy"
        )
        self.agentscope_initialized = False
    
    def _init_agentscope(self):
        """延迟初始化 AgentScope"""
        if self.agent_mode != "agentscope" or self.agentscope_initialized:
            return
        self.agentscope_initialized = True
    
    async def chat(self, query, depth=0):
        """增强对话方法"""
        if self.agent_mode == "agentscope" and depth == 0 and query:
            return await self._agentscope_chat(query)
        return await self._legacy_chat(query, depth)
    
    async def _agentscope_chat(self, query: str) -> bool:
        """使用 AgentScope 管道处理对话"""
        try:
            from core.agents.medical_pipeline import agentscope_medical_flow
            answer = await agentscope_medical_flow(self, query)
            if answer:
                # TTS 输出
                self.tts.tts_one_sentence(
                    self, ContentType.TEXT, content_detail=answer
                )
                self.dialogue.put(Message(role="assistant", content=answer))
                return True
        except Exception as e:
            logger.bind(tag=TAG).error(f"AgentScope 管道失败: {e}")
        
        # 降级到 legacy 模式
        return await self._legacy_chat(query, 0)
```

## 五、关键设计决策

| ADR | 决策 | 理由 |
|-----|------|------|
| **ADR-001** | 采用方案A (Adapter/Wrapper) | 最小风险、渐进迁移、可回退 |
| **ADR-002** | 只利用 AgentScope Python 版实际能力 | Python 版无 HarnessAgent/ServiceLayer/Workspace |
| **ADR-003** | 保留现有音频管道不变 | VAD/ASR/TTS 与 AgentScope 不重叠 |
| **ADR-004** | `AgentMode` 灰度启用 | config.yaml → selected_module.AgentMode 控制 |
| **ADR-005** | 医疗核心函数不重写 | V2 并行流已验证生产，仅编排方式变 |

**修复**: 换为 CPU 版 torch

#### 第4轮：TypeError - funasr tokenizer 为 None

**错误**:
```
TypeError: 'NoneType' object is not callable
```

**根因**: funasr 1.2.6 虽然注册了 `SentencepiecesTokenizer` 类，但模型配置文件 `models/SenseVoiceSmall/config.yaml` 中 `tokenizer_conf.bpemodel` 为 `null`，而 `SentencepiecesTokenizer.__init__` 需要 `bpemodel` 路径来加载 SentencePiece 模型文件。

**修复**: 修改 `models/SenseVoiceSmall/config.yaml`，将 `bpemodel` 指向实际的 bpe model 文件：
```yaml
tokenizer_conf:
  bpemodel: models/SenseVoiceSmall/chn_jpn_yue_eng_ko_spectok.bpe.model
  unk_symbol: <unk>
  split_with_space: true
```

#### 第5轮：UnboundLocalError - funasr 1.2.7 SenseVoiceTokenizer 的静默 except

**错误**:
```
UnboundLocalError: cannot access local variable 'get_tokenizer'
where it is not associated with a value
```

**根因**: 在修复第4轮时将 `tokenizer` 从 `SentencepiecesTokenizer` 改为 `SenseVoiceTokenizer`。funasr 1.2.7 的 `SenseVoiceTokenizer` 函数试图从 `funasr.models.sense_voice.whisper_lib.tokenizer` 导入 `get_tokenizer`，但该路径不存在（funasr 1.2.7 打包时未包含此子模块）。`except` 块仅打印提示信息而不 `raise`，导致函数继续执行，使用未赋值的局部变量 `get_tokenizer`。

```python
# 问题代码（funasr 1.2.7 whisper_tokenizer.py）
def SenseVoiceTokenizer(**kwargs):
    try:
        from funasr.models.sense_voice.whisper_lib.tokenizer import get_tokenizer
    except:
        print("Notice: ...")  # 不 raise，get_tokenizer 未定义
    # ... 继续执行，使用未定义的 get_tokenizer → UnboundLocalError
```

**修复**:
1. 恢复 `tokenizer: SentencepiecesTokenizer`（模型配置文件）
2. 将 funasr 从 1.2.7 降级到 **1.2.6**（`SentencepiecesTokenizer` 在 1.2.6 中工作正常）

```bash
pip install funasr==1.2.6
```

同时修补 `funasr/tokenizer/whisper_tokenizer.py` 的异常处理逻辑（双重 fallback + raise 兜底）：
```python
def SenseVoiceTokenizer(**kwargs):
    try:
        from funasr.models.sense_voice.whisper_lib.tokenizer import get_tokenizer
    except ImportError:
        try:
            from whisper.tokenizer import get_tokenizer
        except ImportError:
            print("Notice: ...")
            raise  # 必须 raise，否则 UnboundLocalError
```

#### 第6轮：端口占用 - HTTP 8003 地址冲突

**错误**:
```
HTTP服务器启动失败: [Errno 10048]
```

#### 第7轮（运行时）：ModuleNotFoundError - jiter.jiter

**错误**（用户询问医疗问题时触发）：
```
ModuleNotFoundError: No module named 'jiter.jiter'
```

**根因**: `jiter==0.14.0` 打包时仅含 Python 3.10 的二进制扩展（`jiter.cp310-win_amd64.pyd`），但环境为 Python 3.11。`openai` 和 `anthropic` 都依赖 `jiter`，当医疗管道调用 `MedicalQwen`（通过 OpenAI 兼容接口）时触发导入失败。

**修复**: 升级到含 cp311 wheel 的版本
```bash
pip install --no-cache-dir --force-reinstall jiter
# jiter 0.14.0 → 0.15.0
```

#### 第8轮（设备连接时）：实例化组件失败

**错误**（设备通过 WebSocket 连接时触发）：
```
ERROR-实例化组件失败: 'TTS'
```

**根因**: `data/.config.yaml` 配置了 `manager-api.url`，`load_config()` 从 Java API 拉取配置。API 返回的 `selected_module` 只有 `ASR` 和 `VAD`，缺少 `TTS`、`LLM`、`Memory`、`Intent` 等字段，且 `TTS` 配置段完全为空。

当设备连接时 `connection.py:135` 调用 `initialize_tts(config)`：

```python
def initialize_tts(config):
    select_tts_module = config["selected_module"]["TTS"]  # ← KeyError
```

被 `except Exception`（行534） 捕获后仅打印 `"实例化组件失败"`，没有堆栈信息，问题被静默吞掉。

**修复**: `config/config_loader.py:101-107` — 增加更多本地配置段的合并：

```python
for local_key in ("log", "agentscope", "mcp_endpoint", "selected_module",
                  "TTS", "LLM", "VAD", "ASR", "Memory", "Intent", ...):
    ...
    if local_key not in config_data:
        config_data[local_key] = local_val
    elif isinstance(local_val, dict) and isinstance(config_data.get(local_key), dict):
        for k, v in local_val.items():
            if k not in config_data[local_key]:
                config_data[local_key][k] = v
```
