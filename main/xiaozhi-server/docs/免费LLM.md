# 全品类免费大模型汇总完整对比（云端永久免费API+限时额度API+聚合平台+本地开源）
覆盖：免费政策、并发限流、上下文、意图识别、工具调用、代码推理、私有化、适用场景、短板，包含你最初关注的 ERNIE-Speed-8K / GLM-4.7-Flash / Hunyuan-Lite。

## 一、分类说明
1. **A类：原厂永久无限免费API（无Token上限、长期商用零成本）**
2. **B类：原厂限时大额免费额度（注册送固定Token，到期付费，仅测试原型）**
3. **C类：第三方聚合平台免费模型（公测/配额制，不建议长期生产）**
4. **D类：开源本地私有化模型（权重永久免费商用，部署后无并发/额度限制）**

# 第一部分：每款模型详细介绍
## A类：原厂永久无限免费云端API
### 1. ERNIE-Speed-8K（百度千帆）
- **免费政策**：永久0Token计费，输入输出无总量上限，无有效期限制，企业商用无隐藏扣费
- **上下文**：8K Token（输入+输出合计上限，超长尾部截断）
- **并发特性**：RPM≈300，等效QPS≈5；多路并发支持，不会单请求锁死；高频批量仅短时限流
- **意图识别**：⭐⭐⭐⭐⭐ 原生对话/客服优化；短句标准意图、实体抽取、槽位填充、批量分类准确率全系最高；支持多轮简单意图记忆
- **工具调用**：完整Function Calling、稳定结构化JSON、适配千帆RAG/智能体
- **核心能力**：内置百度知识图谱+联网搜索，常识、资讯问答强；低延迟（首Token 200–400ms）
- **私有化**：闭源，仅云端API，无法本地部署
- **短板**：仅8K短窗口，万字长文无法处理；代码、复杂数学推理偏弱

### 2. ERNIE-Speed-128K（百度千帆）
- **免费政策**：同Speed-8K，永久无限免费
- **上下文**：128K，弥补8K短板，支持长工单、合同读取
- **并发/意图识别/延迟**：与Speed-8K完全一致
- **差异**：超长文本意图、长文档批量抽取能力大幅提升，其余特性相同

### 3. GLM-4.7-Flash（智谱AI）
- **免费政策**：云端API永久无Token上限；权重MIT开源，本地部署永久免费商用
- **上下文**：200K Token，单次最大输出128K
- **并发特性**：**云端免费档硬性1并发**，同一账号同时仅能跑1条请求，高峰期排队延迟高；本地部署无并发限制（硬件决定）
- **意图识别**：⭐⭐⭐⭐ 擅长**模糊口语、多意图混杂、长文本深层需求、多轮嵌套诉求**；短句标准分类略逊文心Speed
- **工具调用**：全系最强，多层Agent链式调用、任务规划、多工具循环调用稳定
- **核心能力**：30B MoE架构，代码、数学、长文档推理国产免费档顶尖
- **私有化**：支持4/8bit量化本地部署，Ollama/vLLM兼容
- **短板**：云端1并发不适合面向C端线上服务；本地部署最低16G显存/32G内存

### 4. GLM-4.5-Flash（智谱AI）
- **免费政策**：同GLM-4.7-Flash永久免费
- **上下文**：128K，推理速度更快
- **并发**：云端依旧1并发
- **定位**：均衡通用轻量化长文本模型，意图识别、代码弱于4.7-Flash

### 5. Spark-Lite（科大讯飞星火）
- **免费政策**：永久不限Token、无有效期
- **上下文**：64K，单次输出4K
- **并发特性**：QPS≈2，RPM≈120，并发限制严格，不适合高并发业务
- **意图识别**：⭐⭐⭐⭐ 语音对话、教育、政务客服垂直意图优化；支持方言、语音槽位联动
- **工具调用**：基础单层Function Calling，复杂Agent易断裂
- **核心能力**：原生ASR/TTS打通，自带联网搜索，语音机器人首选
- **私有化**：闭源仅云端API
- **短板**：长文本深度推理、工程代码能力一般

### 6. Doubao-Lite / Seed-Mini（火山引擎豆包）
- **免费政策**：每日刷新200万Token永久免费，次日重置，无年度上限
- **上下文**：32K，单次输出8K
- **并发特性**：QPS≈10，并发宽松，中小型线上服务稳定
- **意图识别**：⭐⭐⭐⭐ 电商、短视频、小程序用户口语意图解析优秀，多轮记忆稳定
- **工具调用**：标准Function Calling，JSON输出稳定
- **核心能力**：字节生态打通（抖音/小程序），流式延迟低
- **私有化**：闭源仅云端API
- **短板**：无200K+超长上下文，复杂数学推理中等

## B类：限时额度免费（非永久无限，仅原型测试）
### 1. Hunyuan-Lite（腾讯混元）
- **免费政策**：新账号一次性赠送10万Token，有效期12个月，额度耗尽全额付费，不属于无限永久免费
- **上下文**：256K输入窗口，单次输出上限仅6K Token
- **并发特性**：默认5路并发，全系云端免费档并发上限最高，适合离线批量任务
- **意图识别**：⭐⭐ 仅清晰短句简单分类可用；模糊口语、多意图、长工单极易混淆、幻觉严重；多轮槽位丢失明显
- **工具调用**：仅基础单层工具调用，复杂链式Agent失效
- **核心能力**：轻量化MoE，批量文本吞吐高，适配企业微信、小程序
- **私有化**：闭源仅腾讯云API
- **短板**：免费额度极少、推理/代码垫底、长输出受限

### 2. Qwen-Turbo / Qwen-Long（阿里通义千问）
- **免费政策**：实名送100万Token/模型，90天到期清零，学生额外赠额度
- **上下文**：Turbo 128K、Long百万字符超长窗口
- **意图识别**：⭐⭐⭐⭐⭐ 长工单、批量商品意图、行业文档抽取极强
- **适用**：原型验证，正式业务必须付费

### 3. DeepSeek V4-Flash
- **免费政策**：每日500万Token刷新试用额度，非永久无上限
- **优势**：复杂多意图拆解、代码/数学推理顶尖

# 第四部分：通用避坑要点
1. **区分“永久无限免费”和“限时赠额度”**
   Hunyuan-Lite、通义千问、DeepSeek试用包都有额度期限，长期线上业务不能做主模型；只有文心Speed全系、GLM云端、星火Lite、豆包每日刷新属于可持续免费。
2. **GLM免费云端1并发硬限制**
   任何面向C端多用户、高并发线上系统禁止依赖GLM免费云端API，必须本地私有化或付费升级。
3. **意图识别取舍核心规则**
   - 标准化短句客服、固定分类标签 → 文心ERNIE-Speed
   - 用户口语混乱、长篇诉求、多意图叠加 → GLM-4.7-Flash
   - 仅离线简单文本过滤、无交互需求 → 混元Lite/硅基流动小模型
4. **并发能力优先级**
   Doubao-Lite(QPS≈10) > ERNIE-Speed(QPS≈5) > Hunyuan-Lite(5路) > Spark-Lite(QPS≈2) > GLM云端(1并发)
5. **本地开源模型无任何限流、无额度、无云端隐私泄露，处理敏感工单、医疗、企业内部数据首选**
